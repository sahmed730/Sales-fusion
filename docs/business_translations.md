# 🗣️ Technical-to-Business Translator

This guide provides standardized translations for common data science terminology used in the Sales-Fusion Platform. Use this to ensure clear communication with non-technical stakeholders.

| Technical Term | Business Translation | When to Use It |
|---|---|---|
| **Prophet Model** | Trend Forecaster | When explaining how we predict future baseline revenue. |
| **XGBoost Algorithm** | Demand Prediction Engine | When discussing how we know exactly how many specific items a region will buy. |
| **Isolation Forest** | Anomaly Detector | When highlighting weird, unusual, or suspicious behavior in the data (like sudden drops in revenue). |
| **MAPE (Mean Absolute Percentage Error)** | Forecast Error Rate | When stakeholders ask "How accurate is this prediction?". |
| **SHAP Values** | Key Drivers | When explaining *why* a certain product's demand is high or low (e.g. "The key driver was the weekend promo"). |
| **K-Means Clustering** | Customer/Region Grouping | When explaining how we grouped similar performing stores or customers together to analyze them as a single block. |
| **P-Value** | Confidence Level | Instead of saying "p < 0.05", say "We are 95% confident that this marketing campaign actually worked, rather than being a random fluke." |
