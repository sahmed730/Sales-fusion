# Contributing to Sales-Fusion

Welcome to the Sales-Fusion project! We are excited to have you contribute to our self-optimizing, agentic AI analytics platform.

## Getting Started

1. **Clone the repository** and install dependencies:
   ```bash
   pip install -r requirements.txt
   pip install -e .
   ```

2. **DVC for Data**:
   Ensure you have DVC installed and pull the latest data:
   ```bash
   dvc pull
   ```

## Workflow

We follow a structured workflow based on Agentic AI skills:
- **Data Quality**: Ensure any new data pipelines include validation scripts.
- **Analysis**: Use the provided modules in `scripts/analysis/`.
- **Documentation**: Always update `data_dictionary.md` or relevant files when changing schemas.

## Pull Requests
- Please ensure tests pass and code is formatted.
- Provide a summary of the changes and the associated agentic skills used.

Thank you for contributing!
